# Avatar model asset

Place the final stylized game-character GLB here:

/public/models/avatar/character.glb

The app is configured to load this model automatically.

Requirements:
- Original stylized cartoon character
- Mobile-game silhouette
- Facial rig or facial mesh support if available
- Clean materials and animation support
- No realistic human reproduction

This folder is reserved for the final production asset and should be replaced with the shipped character model when available.
